# ATELIER — Furniture E-commerce

A modern, high-end furniture e-commerce website built with WordPress & WooCommerce, featuring a bespoke Full Site Editing (FSE) block child theme, custom controlled product import pipeline, and robust governance documentation.

## Overview
- **Platform:** WordPress / WooCommerce
- **Active Theme:** 	wentytwentyfive-child (Bespoke Atelier Design System)
- **Key Features:**
  - Modern, responsive typography and curated color palette (	heme.json + style.css)
  - Custom block templates for Homepage, Product Catalog (Archive), and Single Product
  - Controlled catalog import pipeline with transaction isolation and multi-pathway recovery
  - Enterprise governance and defect management audit trail

## Project Structure
- 	hemes/twentytwentyfive-child/: Custom block theme templates, template parts, design tokens, and assets.
- plugins/: Controlled catalog import engine (un_controlled_import.php).
- plugins/docs/: Architectural governance, gate approval matrices, and safety audit reports.
- docs/: Historical project reports and audit milestones.
